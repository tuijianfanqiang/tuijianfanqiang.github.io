引言：为什么你需要小火箭？

在这个信息爆炸的时代，网络自由已成为现代人的基本需求。然而，地域限制、内容审查等问题常常成为我们获取信息的障碍。小火箭 Shadowrocket 作为 iOS 生态中最强大的网络代理工具之一，以其简洁的界面、强大的功能和稳定的性能，成为数百万用户突破网络边界的首选利器。本文将带你全面了解这款工具，从基础概念到高级配置，让你轻松掌握科学上网的艺术。

第一章：认识小火箭 Shadowrocket

1.1 什么是小火箭？

小火箭 Shadowrocket 是一款专为 iOS 设备设计的网络代理客户端，支持 Shadowsocks、Vmess、Trojan 等多种主流代理协议。它不仅能帮助你访问被限制的网站和服务，还能有效保护你的网络隐私，防止数据被窃取或监控。

1.2 小火箭的核心优势

  • 用户友好：界面简洁直观，新手也能快速上手。
  • 多协议支持：兼容 Shadowsocks、Vmess、Trojan 等多种协议，适应不同网络环境。
  • 灵活配置：支持自定义 DNS、规则设置和代理策略，满足个性化需求。
  • 隐私保护：通过加密传输数据，防止 ISP 或第三方监控你的网络活动。

第二章：下载与安装

2.1 官方渠道获取

小火箭 Shadowrocket 在 App Store 中提供下载，但由于某些地区的限制，可能需要切换 Apple ID 地区或通过其他方式获取。

步骤：
1. 打开 App Store，切换至支持 Shadowrocket 的地区（如美区、港区）。
2. 搜索 "Shadowrocket" 并购买（通常售价 $2.99）。
3. 下载并安装。

2.2 替代下载方式

如果无法通过 App Store 获取，可尝试以下方法：
- 通过第三方签名工具（如 AltStore）安装 IPA 文件。
- 使用企业证书版本（需注意安全性）。

⚠️ 注意：非官方渠道可能存在安全风险，建议优先选择正版。

第三章：基础配置教程

3.1 添加服务器

  1. 打开 Shadowrocket，点击右上角 + 按钮。
  2. 选择代理类型（如 Shadowsocks、Vmess）。
  3. 填写服务器信息（地址、端口、密码、加密方式等）。
  4. 保存并返回主界面。

3.2 连接与断开

  • 连接：点击服务器名称，再点击底部 连接 按钮。
  • 断开：再次点击 连接 按钮即可。

3.3 检查连接状态

  • 成功连接后，状态栏会显示 VPN 图标。
  • 可在 Shadowrocket 主界面查看实时流量和连接时长。

第四章：高级功能与优化

4.1 自定义 DNS

优化 DNS 可以提升解析速度并避免污染：
1. 进入 设置 → DNS。
2. 添加公共 DNS（如 1.1.1.1、8.8.8.8）。
3. 启用 DNS over HTTPS (DoH) 增强隐私。

4.2 规则配置

通过规则可以实现智能分流（如国内直连、国外走代理）：
1. 进入 配置 → 规则。
2. 添加规则集（如 GFWList、自定义规则）。
3. 设置匹配策略（DIRECT、PROXY、REJECT）。

4.3 日志与调试

如果遇到连接问题，可查看日志排查：
1. 进入 日志 选项卡。
2. 检查错误信息（如超时、认证失败）。
3. 根据日志调整服务器或网络设置。

第五章：常见问题与解决方案

5.1 连接失败怎么办？

  • 检查服务器信息：确保地址、端口、密码正确。
  • 更换协议：尝试 Shadowsocks 或 Vmess 不同加密方式。
  • 网络环境：某些 WiFi 可能屏蔽代理，可切换 4G/5G 测试。

5.2 如何提升速度？

  • 选择低延迟的服务器。
  • 启用 UDP 转发（若支持）。
  • 关闭不必要的规则以减少性能开销。

5.3 是否支持多设备？

Shadowrocket 仅限 iOS 设备，但可通过订阅方式同步服务器配置到其他客户端（如 Clash、Surge）。

第六章：安全与隐私建议

  1. 定期更换密码：避免长期使用同一组认证信息。
  2. 启用 TLS 加密：Vmess 协议建议搭配 TLS 以增强安全性。
  3. 避免公共 WiFi：即使使用代理，公共网络仍可能存在风险。

FAQ

Netch 的透明代理适合哪些应用场景？
透明代理通过 TUN 或 WinDivert 拦截系统 IP 层流量，无需配置每个应用。适合全局科学上网、在线游戏或对局域网设备统一代理的场景。
Trojan 服务端出现 handshake timeout 如何处理？
该错误通常由网络延迟或证书配置不一致导致。请检查服务器带宽是否充足、TLS 证书链完整，并确保客户端 SNI 与证书匹配。必要时更换节点或优化拥塞控制算法。
SSR 混淆方式如何提升抗封锁能力？
混淆方式可将流量伪装成正常 HTTPS 或 HTTP 数据，降低被 DPI 检测风险。合理选择协议和混淆组合，可以提升节点稳定性和长期可用性，确保科学上网顺畅。
Clash 的策略组可设置延迟阈值吗？
可以。用户可定义延迟阈值，当节点延迟超过设定值时，策略组会自动切换至其他低延迟节点，提高网络速度和稳定性，优化访问体验。
V2Ray 的路由规则如何实现国内直连？
通过配置域名列表或 IP 段，将国内流量指向直连出口，而国外流量走代理节点。结合策略组和定期更新规则，可保持国内访问速度，同时优化海外访问体验。
Mellow 使用透明代理时如何避免 DNS 泄露？
在 Mellow 中启用 fake-ip 或内置 DNS 解析功能，并将上游 DNS 指定为 DoH/DoT 服务，确保所有 DNS 请求通过代理转发而非本地解析，从而避免 ISP 或本地网络捕获实际访问域名。
Nekobox 是否支持多客户端同时管理节点？
支持。Nekobox 可以独立管理多个客户端，如 Shadowsocks 和 Clash 节点，互不干扰。结合策略组，可实现多客户端流量分流和网络优化，提高便利性和效率。
为什么使用 CDN 后仍然能被封？如何规避？
若 CDN 回源 IP 或配置不当可能泄露真实服务器信息，或者 CDN 本身被目标防火墙识别。应启用完整的反向代理配置、隐藏源站 IP 与禁用不必要的服务，必要时使用多级中转或更换 CDN 供应商。
Sing-box 精确端口分流如何提升游戏连接？
Sing-box 可按端口设置流量分流规则，将游戏流量分配到低延迟节点。结合策略组使用，可保证游戏连接稳定，减少延迟和掉线，提高流畅度和网络体验。
如何提高 Vmess 协议的安全性？
可通过启用 TLS 加密、使用安全端口（如 443）、结合 WebSocket 或 gRPC 传输方式来提升安全性。同时，避免公开分享 UUID，定期更换节点参数能进一步减少被封风险。
